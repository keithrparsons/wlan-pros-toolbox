   **External sources (fetched 12 Nov 2026):**

   - Flutter needs a Windows host. Visual Studio with the "Desktop development with C++" workload (`Microsoft.VisualStudio.Workload.NativeDesktop`). Visual Studio is "only supported on Windows" ([Flutter Windows setup](https://docs.flutter.dev/platform-integration/windows/setup)). Cross-compile from macOS is an open feature request with no current plan to implement it ([flutter/flutter#59735](https://github.com/flutter/flutter/issues/59735)). Official deploy page: `flutter build windows` output is the whole Release folder (exe, DLLs, `data/`), and "it would be relatively simple to add this folder to a Windows installer such as Inno Setup, WiX, etc." Include the VC++ redistributables (`msvcp140.dll`, `vcruntime140.dll`, `vcruntime140_1.dll`). Path: `build\windows\x64\runner\Release\` ([Build and release a Windows desktop app](https://docs.flutter.dev/deployment/windows), [Building Windows apps](https://docs.flutter.dev/platform-integration/windows/building)).
   - Windows on ARM / Parallels: `flutter build windows` targets the host architecture. Shipping x64 from an ARM VM is not a supported stable path (community CMake workarounds exist and are fragile; VC redist files from an ARM System32 are wrong). Do not use a Parallels ARM VM as the shipping build host. That matches the repo's own `msix_config` comment.
   - Inno Setup produces a single setup `.exe` with Start Menu / Desktop shortcuts and uninstaller. Official site: [jrsoftware.org/isinfo.php](https://jrsoftware.org/isinfo.php). Current recommended release is Inno Setup 7 (7.1.1 dated 28 Oct 2026). Commercial use: the authors "request" that commercial users buy a license; it is "not strictly required." A license may be bought later, once the installer is ready for production. A CI machine counts as a user; a single-user license is the minimum they ask for. Prices are loaded live at checkout on [jrsoftware.org/isorder.php](https://jrsoftware.org/isorder.php) (not printed as static text on the page). Confirm the price at that page before any purchase. Do not buy without Keith's yes.
   - MSIX sideload: a self-signed MSIX is for dev and testing only. Microsoft: self-signed "Blocks installation for public users"; the customer would have to trust the cert on their machine. A publicly trusted signing cert is required for customers. ([Code signing options](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/code-signing-options), fetched 12 Nov 2026.)
   - SmartScreen ([SmartScreen reputation](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation), [Code signing options](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/code-signing-options), both fetched 12 Nov 2026):
     - Microsoft Store: no SmartScreen warning (Microsoft re-signs). This remains the cleanest install path. Keep it on the site.
     - Valid OV/EV or Azure Artifact Signing: early downloads can still warn until reputation builds (weeks, and Microsoft says "hundreds of clean installs"; no exact threshold). The verified publisher name is shown. Reputation can carry to later releases signed with the same publisher identity.
     - Unsigned: "Windows protected your PC"; the user must choose "Run anyway." Enterprise policy can block that entirely. Each new file hash starts at zero reputation. On Windows 11, Smart App Control "will block execution of unsigned files unless the file has a positive reputation."
     - Self-signed: same as unsigned for public users.
     - EV no longer grants instant SmartScreen bypass (changed 2024). Microsoft: paying a premium for EV "solely to avoid SmartScreen warnings is no longer justified."
   - Azure Artifact Signing (formerly Trusted Signing), Microsoft's recommended non-Store option:
     - Basic: $9.99 per account per month, 5,000 signatures, then $0.005 each; one certificate profile of each type. Premium: $99.99 / 100,000. ([SKU page](https://learn.microsoft.com/en-us/azure/artifact-signing/how-to-change-sku), [product page](https://azure.microsoft.com/en-us/products/artifact-signing), fetched 12 Nov 2026. The Azure pricing-details page hides the dollar figures behind a sign-in; the SKU page prints them.)
     - Not pro-rated: the full month is billed when the Artifact Signing account is created, even before you start signing. ([FAQ](https://learn.microsoft.com/en-us/azure/artifact-signing/faq).)
     - Requires a **paid** Azure subscription. Free, trial, and sponsored subscriptions are rejected. ([FAQ](https://learn.microsoft.com/en-us/azure/artifact-signing/faq).)
     - Public Trust eligibility: organizations in the US, Canada, the EU, the UK, Australia, New Zealand, Japan, South Korea, Singapore, Switzerland, Norway, and Israel; individual developers in the US or Canada. ([Quickstart](https://learn.microsoft.com/en-us/azure/artifact-signing/quickstart), fetched 12 Nov 2026.) A second Microsoft page, [Code signing options](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/code-signing-options), lists a shorter org set (USA, Canada, EU, UK only). The two official pages disagree. Wireless LAN Professionals, Inc. is a US organization, so it is on both lists. Identity validation takes a few business days. No hardware token. Integrates with GitHub Actions (`azure/trusted-signing-action` is mentioned in Microsoft's MSIX signing docs).
     - CN on the cert is the legal entity name; it cannot be customized. ([FAQ](https://learn.microsoft.com/en-us/azure/artifact-signing/faq).)
   - Traditional OV / EV certificates, since 1 Jun 2023, must keep the private key on a FIPS-class token or cloud HSM (CA/Browser Forum). Rough prices fetched 12 Nov 2026: SSL.com OV $129/year on their product page, YubiKey extra $379, or eSigner cloud (separate subscription); SSL.com EV $349/year ([SSL.com OV](https://www.ssl.com/products/software-integrity/code-signing/ov/), [SSL.com EV](https://www.ssl.com/products/software-integrity/code-signing/ev/)). DigiCert's own page listed a 12-month subscription around $528 OV and $744 EV (options for token / KeyLocker add more). Microsoft's comparison quotes OV typically $150-$300/year and EV $400+/year. Re-confirm at purchase time. Fallback if Azure identity validation stalls, from the June 2026 team plan: SSL.com OV with eSigner (CI-capable, no physical token).
   - GitHub Actions: both `wlan-pros-toolbox` and `toolbox-wlanpros-site` are public, so standard GitHub-hosted runners are free for these repos. Use `windows-2022`, not `windows-latest`.
